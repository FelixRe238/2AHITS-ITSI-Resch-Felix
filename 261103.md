**Übung  2.1 (Netzwerk NAT/Bridged)**

IP-Adressen:
Bridged:
- Kali IP-Adresse: 192.168.1.52
- Metasploitable IP-Adresse: 192.168.1.51
- Host: 192.168.1.50 

NAT:
- Kali IP-Adresse: 192.168.124.137
- Metasploitable IP-Adresse: 192.168.124.147
- Host: 192.168.1.50 

Auf Bridged funktioniert ein ping von Kali zu metasploitable und umgekeht, sowie ein Ping zum Host und zu einem anderen Kali system.
Bei NAT funktioniert das Pingen eines anderen Kali systems nicht alles andere aber schon.

**Übung  2.2 (Dateitransfer per Webserver Metasploitable → Kali)**

Anlegen einer Textdatei in Metasploitable
```
echo "Test" > test.txt
```
Webserver: apache2 
```
$ps ax
```
Herausfinden auf welchem Port der Webserver läuft
```
$ sudo netstat -tlpn | grep apache
```
Standard Verzeichniss in dem der Webserver seine Dateien Ablegt: /var/www/test
Hierhin die Datei verschieben.

In Kali Herunterladen und den inhalt in eine neue datei kopieren:
```
curl 192.168.124.147/test/test.txt > test.txt
```
